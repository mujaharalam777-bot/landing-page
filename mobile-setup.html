[STEP 1] EDIT index.html ON PHONE - 8 MINUTES

OPEN FILE IN ACODE

  • 1. Open "Acode" app
  • 2. Tap "≡" > "Open Folder" > Select your "index.html" file

CHANGE SALON NAME + WHATSAPP

  • 1. Tap "🔍" Search icon on top
  • 2. Search for: const CONFIG
  • 3. CHANGE ONLY THESE 4 LINES:
const CONFIG = {
  SALON_NAME: "StyleHub Elite",  <-- YOUR SALON NAME
  COLOR_PRIMARY: "#FFFFFF",      
  WHATSAPP_HER: "919876543210",  <-- 91 + FEMALE NUMBER
  WHATSAPP_HIM: "919876543211",  <-- 91 + MALE NUMBER
  ...
}
EXAMPLE: 9876543210 = 919876543210

REPLACE NUMBER EVERYWHERE

  • 1. Tap "🔍" Search icon
  • 2. Search: 919876543210
  • 3. Tap "..." > "Replace All" > Put your number > "Replace All"

CHANGE PHOTOS - USE IMGBB

  • 1. Open Chrome > Go to imgbb.com > "Start Uploading"
  • 2. Upload 4 stylist photos + 6 salon photos
  • 3. Copy "Direct Link" for each photo
  • 4. Back in Acode. Search: const TEAM > Replace 4 links
  • 5. Search: const IG_IMGS > Replace 6 links

SETUP WHATSAPP ASSISTANT

  • 1. Search: const waReplies
  • 2. Edit Location, Price, Offer, Booking messages
const waReplies = {
  "location": "📍 We are at [YOUR ADDRESS]. Open 10AM-9PM.",
  "prices": "💇‍♀️ PRICE LIST 💇‍♂️ HER: Rs 499, HIM: Rs 299",
  "offer": "🔥 TODAY'S OFFER 🔥 20% OFF on Haircut",
  "booking": "✅ To book tell me: Name, Service, Date, Time"
};

SAVE FILE

Tap "💾" Save icon on top
