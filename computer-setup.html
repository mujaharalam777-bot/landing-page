STYLEHUB ELITE - COMPLETE COMPUTER SETUP GUIDE

Version 1.0 | Single File Website | No Coding Required

This is a premium 1-file salon website with WhatsApp Booking, Admin Panel, 360 Tour, Multi-Language. Just follow the steps below.

[STEP 0] WHAT YOU NEED

  • 1. A Computer or Laptop with Internet
  • 2. Notepad++ or VS Code - Free. Download from Google
  • 3. Google Chrome Browser

[STEP 1] EDIT THE FILE - 10 MINUTES

TASK 1: OPEN THE FILE

  • 1. Right Click on "index.html"
  • 2. Click "Open with" > "Notepad++" or "VS Code"

TASK 2: CHANGE SALON NAME AND WHATSAPP NUMBER - MOST IMPORTANT

  • 1. Press Ctrl + F on keyboard. A search box will open
  • 2. Search for: const CONFIG
  • 3. You will see this. Change these 4 lines:
SALON_NAME: "StyleHub Elite",  <-- PUT YOUR SALON NAME HERE
COLOR_PRIMARY: "#FFFFFF",      <-- KEEP THIS WHITE
WHATSAPP_HER: "919876543210",  <-- WHATSAPP FOR FEMALE. USE 91 + NUMBER
WHATSAPP_HIM: "919876543211",  <-- WHATSAPP FOR MALE. USE 91 + NUMBER
Example: For India number 9876543210, write 919876543210

TASK 3: REPLACE PHONE NUMBER EVERYWHERE

  • 1. Press Ctrl + F
  • 2. Search for: 919876543210
  • 3. Click "Replace All" and put your number

TASK 4: CHANGE CITY AND ADDRESS

  • 1. Press Ctrl + F
  • 2. Search for: Your City
  • 3. Replace "Your City" with "Your City, Your State"

TASK 5: CHANGE PHOTOS

  • 1. Press Ctrl + F
  • 2. Search for: const TEAM
  • 3. You will see 4 photo links. Replace with your stylist photos.
  • To get photo link: Upload to imgbb.com > Copy "Direct Link"
  • 4. Press Ctrl + F
  • 5. Search for: const IG_IMGS
  • 6. Replace these 6 links with your salon work photos

TASK 6: CHANGE SERVICES AND PRICES

  • 1. Press Ctrl + F
  • 2. Search for: const SERVICES
  • 3. Edit "her", "him", "couples" sections with your services and prices

TASK 7: SAVE THE FILE

Press Ctrl + S to save

[STEP 2] TEST ON YOUR COMPUTER

  • 1. Double Click "index.html"
  • 2. It will open in Google Chrome
  • 3. Check all buttons, forms, and links
